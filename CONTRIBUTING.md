# Contributing to SLIDEVERSE

Thank you for helping improve SLIDEVERSE!

## Before you start

1. Search existing issues and pull requests to avoid duplicate work.
2. For a major new component, open an issue first to discuss the idea.
3. Keep each slider visually and functionally distinct. Do not submit duplicates with only minor color or spacing changes.

## Component requirements

Each new slider should include:

- A descriptive folder name and unique component ID.
- `index.html`, stylesheet(s), and JavaScript or React source as applicable.
- A short `README.md` describing features, dependencies and usage.
- Responsive behavior and tested controls.
- Keyboard and accessibility considerations.
- Reduced-motion handling where animation is used.
- Original assets or assets with redistribution permission.

## Suggested folder naming

`short-descriptive-name/` at the repository root, plus one entry in `assets/js/sliders.js`.

Example: `product-showcase-slider/`

## Pull request process

1. Fork the repository.
2. Create a branch: `feat/your-slider-name`.
3. Make focused changes.
4. Test in current desktop and mobile-sized viewports.
5. Update relevant documentation.
6. Open a pull request and explain what changed, how to test it, and any dependencies.

Do not commit API keys, passwords, private payment information, or personal data.

By submitting a contribution, you agree that your contribution is provided under the repository's MIT License, unless you clearly state otherwise and the maintainer agrees.
