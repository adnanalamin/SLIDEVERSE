## ✨ About

SLIDEVERSE aims to become a free, open-source library of **200+ unique slider and carousel designs**. Each component will include clean source code, a live preview, responsive behavior and usage instructions.

The collection is being developed in stages. A slider will be listed as available only after its implementation and testing are complete.

## 🧰 Technologies

- HTML5 and CSS3
- Vanilla JavaScript
- React
- Tailwind CSS
- Bootstrap 5

Not every component uses every technology. Each slider will clearly list the technologies it requires.

## 🚀 Getting started

The collection is under active development. As components are added, each component folder will contain its own instructions.

For a standalone HTML/CSS/JavaScript example:

1. Open the component folder.
2. Read its `README.md`.
3. Open its `index.html` in a browser, or use a local development server if the example requires one.
4. Check the listed dependencies before copying the code into your project.

## 🧩 Component quality goals

Every published component should aim to include:

- Responsive layouts for mobile, tablet and desktop
- Working previous/next controls and pagination where relevant
- Touch and swipe support where appropriate
- Keyboard interaction and accessible labels
- Reduced-motion support
- Clear, reusable and commented code
- No broken controls or unfinished placeholder interactions
- A preview and setup instructions
