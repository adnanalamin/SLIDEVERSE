# Security Policy

## Reporting a vulnerability

Please do not publish exploitable security vulnerabilities in a public issue.

Report them privately to the repository maintainer through a verified contact method on the GitHub profile. Include:

- A description of the issue and its potential impact.
- Steps to reproduce, if safe to provide.
- A suggested fix, if you have one.

Do not include real user data, credentials, private keys or payment details in a report.

## Scope

This policy covers code maintained in this repository. Third-party libraries and hosted services may have separate security policies.
